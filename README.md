# Week06 SSOT Project · 工程化写作与一源多端交付

> 南昌大学《人机协同程序设计》第 6 周实践课作业
> 课题：《“凌晨一点半综合征”：睡前短视频沉迷机制与大学生断网干预对照实验》
> 作者：潘炜昊（5715126019）

本仓库演示一条完整的 **“题眼锚定 → 分层规约 → 原始数据填槽 → 带行号局部差分修补 → 一源多端编译”** 工程化写作流水线：唯一事实源是一份 100% 纯语义的 `report.md`，幻灯片与 A4 研报全部由编译器从它派生，不允许任何手工复制。

## 目录结构

```
Week06_SSOT_Project/
├── raw_data.json          # 原始实验数据台账（所有定量指标的唯一起源）
├── outline_spec.md        # 题眼 + Mermaid 思维导图 + 四章大纲 + 段落槽位规约
├── report.md              # 纯语义单一事实源母稿（100% CommonMark）
├── annotated_prompts.md   # ROCA 提示词链批注 + 局部差分修补对比 + 人机协同三反思
├── SKILL.md               # 固化五步工程化写作 SOP 的可复用技能文件
├── ssot_compiler.py       # 一源多端编译器（三道门禁 + 双端构建）
└── dist/                  # 编译产物（请勿手改，改母稿后重新编译）
    ├── slides.html        # 16:9 宽屏演示幻灯片（← → 翻页）
    ├── report.pdf         # A4 学术排版研报
    ├── report.typ         # Typst 源码
    ├── slides.marp.md     # Marp 源码
    └── report_a4_preview.html
```

## 快速开始

```bash
python ssot_compiler.py
```

三条门禁全部通过后会生成 `dist/` 下的全部产物：

| 门禁 | 检查内容 |
| :--- | :--- |
| Gate 1 纯语义 | `report.md` 中 0 个 HTML 标签、0 个残留 `[待填槽位]`，并打印第 1–27 行与第 37 行之后的上下文散列 |
| Gate 2 视觉预算 | 幻灯片每页要点 ≤ 6 条、标题字数不溢出，自动切分为 16:9 页面 |
| Gate 3 双端构建 | 同时产出 `slides.html` 与 `report.pdf`（优先 Typst，缺省时启用零依赖 Python PDF 引擎） |

编译器不依赖任何第三方库；若系统装有 `typst` 会自动切换为矢量排版引擎。

## 核心数据（源自 `raw_data.json`）

| 指标 | 对照组 G_Control (N=40) | 干预组 G_Exp (N=40) | 变化 |
| :--- | :--- | :--- | :--- |
| 30 分钟入睡达标率 | 42.5%（17/40） | 85.0%（34/40） | +42.5 个百分点 |
| 平均入睡潜伏耗时 | 46.0 分钟（2760 秒） | 14.0 分钟（840 秒） | 缩短 69.6%（净省 32.0 分钟） |
| 次日早八困倦率 | 72.5%（29/40） | 7.5%（3/40） | −65.0 个百分点 |

## 一源多端的一致性验证

改母稿一处 → 重新编译 → 两端产物同步变化 → 回滚后散列逐字节还原。实测单次编译约 0.7 秒，验证过程记录在 `annotated_prompts.md` 第三部分。

## 说明

- `dist/` 中的文件是编译产物，**不要直接编辑**；所有修改都应在 `report.md` 中进行。
- 本仓库不含任何虚构统计数据，未在 `raw_data.json` 中出现的指标一律不出现在报告正文中。
